# ds-workflow-intro

## About the Project
This project introduces the basics of Data Science. It covers the definition of Data Science, its lifecycle, real-world applications, and a first exploration of the Titanic dataset.

## Objectives
- Understand what Data Science is and how its lifecycle works
- See how Data Science is used in healthcare, finance, and retail
- Explore a beginner-friendly dataset and document its structure
- Practice clean Git and GitHub habits

## Repository Structure
- `README.md` - project overview (this file)
- `data/raw_dataset.csv` - the raw Titanic dataset
- `docs/research_report.md` - research on Data Science, its lifecycle, and applications
- `docs/dataset_exploration.md` - column names, types, and missing values
- `.gitignore` - files Git should ignore

## How to Navigate
1. Start with `docs/research_report.md` to learn the concepts.
2. Open `docs/dataset_exploration.md` to see how the data is structured.
3. Check `data/raw_dataset.csv` to view the raw data.

## Dataset
The Titanic dataset lists passengers aboard the Titanic, with details such as age, sex, ticket class, and whether they survived.
